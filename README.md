# neuroquo-web

Web pública de NEUROQUO: https://neuroquo.es

Web estática publicada con GitHub Pages desde la rama `main`. El dominio está en `CNAME` y en la zona DNS de DonDominio.

- `index.html`: portada.
- `aviso-legal.html`, `privacidad.html`, `cookies.html`: páginas legales (titular: Homancan S.L.).
- `css/fuentes.css` y `fonts/`: tipografías alojadas aquí (sin Google Fonts, sin cookies).
- `assets/`: logotipos.
